# BrandBoost Lead Desk

A standalone, installable prospect tracker for Harare. Uses browser localStorage on this device; no server sync or automated Facebook/WhatsApp messaging. Export CSV or JSON backups regularly.

## Install
Open the deployed GitHub Pages URL in Chrome on Android, then use the browser menu → Add to Home screen / Install app.

## Privacy
Lead data stays in this browser profile on this device unless manually exported. Clearing site data can erase it. Use only legitimate public business contact details and send messages manually; no scraping or bulk automation.
